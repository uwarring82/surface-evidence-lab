# Preserved sources and provenance records

Seven unchanged files accompany the Seibert, Croshaw and Pálinkás source records. The Seibert article PDF is not among them: its redistribution permission is unverified, so it is kept in the local source archive. See the [manifest](../literature/source-manifest.md) for individual terms, provenance, identifiers, timestamps and hashes, and [RIGHTS.md](../RIGHTS.md) for the distribution decision.

XML does not include externally referenced image bytes. The Figshare JSON is a deposit record, not the dataset ZIP. The Croshaw supplement is preserved but was not comprehensively inspected. `seibert-2020-record.html` is a browser-verification page, not a rights record; it is kept only as evidence that the rights retrieval failed.
