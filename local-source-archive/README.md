# Local source preservation

The complete handoff ZIP contains `xu-2024.xml` (CC BY-NC 4.0) and the unchanged `lu-2014.pdf` (CC BY-NC-ND 4.0). Their contents are excluded from the default Git commit. The public teaching core uses links and separate commentary for these readings.

Per-source rights, retrieval details and hashes remain in the [manifest](../literature/source-manifest.md). A normal clone may contain only this README. Use `--require-local-archive` with the source verifier when checking the complete handoff.
