# Decision record

Consolidated 17 September 2026 from the discussion and revised scout. These are project working decisions, not completed experiments.

| ID | Decision | Consequence |
|---|---|---|
| D01 | Begin with a standalone literature teaching lab. | No lab agreement, live repository integration or graph implementation blocks the packet. |
| D02 | Accept the first-pass scout as the selection milestone. | Do not claim a completed bounded survey or absence of suitable literature. |
| D03 | Use Seibert Fig. 2 and Croshaw Fig. 5 as the core. | Teach variable controls and measurement-induced changes; Croshaw is not merely an extension. |
| D04 | State the changed teaching physics in the front matter. | Gas/organic contamination and probe-induced changes do not validate the bulk-diffusion research question. |
| D05 | Keep Xu/Lu as links and separate commentary in the public teaching core. | Preserve the XML/PDF locally under their own terms; no adapted figure composites from them are planned. |
| D06 | Separate identity, spatial correspondence and state history. | A changed state does not invalidate same-object or same-region identity. |
| D07 | Factor the inherited status enum into independent dimensions. | Feed this defect back to the unfrozen time-reference design; no claim that an upstream implementation has been changed. |
| D08 | Preserve physical events and assertion revisions explicitly. | Acquisition can change the specimen; publication, acquisition and record dates must remain distinct. |
| D09 | Store scoped evidence/uncertainty; queries set requirements. | An infrastructure confidence label is not the physical mechanism finding. |
| D10 | Keep unmet safeguards separate and visible. | Short interventions, a composition dispute or a hypothetical revision cannot silently pass longitudinal, gap or exact-correspondence criteria. |
| D11 | Preserve source bytes, dates, versions and hashes. | Editorial corrections belong in commentary; failed downloads and uninspected data remain recorded. |
| D12 | Bound any later formal survey by effort. | Set a remaining allowance at launch; five person-days total is the intended cap, with reliable prior effort accounted for. Declare an outcome at the cap. |
| D13 | Package a repository handoff without selecting a project licence or remote. | Those choices remain with the project lead; source licences are retained. |
| D14 | Publish the repository publicly on GitHub (17 September 2026). | Hosting and visibility are settled; the original-material licence and named maintainer remain open, and the local-archive exclusion still applies. |

The public-core packaging decision is a chosen scope, not a general claim that all NC material is barred from public sharing or that every unchanged panel arrangement is an adaptation.
