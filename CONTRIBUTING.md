# Working on this project

Start with [STATUS.md](STATUS.md), the [task card](planning/task-card.md) and [rights](RIGHTS.md). Keep changes small enough to review against a specific teaching need or evidence requirement.

- Separate source reports, direct inspection and inference. Cite the paper plus page, panel or section when possible.
- Preserve original source bytes. Add new versions as new records; retain prior hashes, retrieval dates and correction history. Editorial notes belong in project text.
- Do not convert same-paper, same-holder or same-modality comparisons into same-specimen or same-region claims without evidence.
- Keep source assertion, evidence availability, disagreement and quantitative uncertainty distinct. Unknown is not false, and absence of a logged event is not proof it did not occur.
- Preserve the distinctions among teaching physics, research physics and infrastructure validation. Update the unmet-requirements register only when its closure evidence exists.
- Before distributing figures, follow the per-source decision and document attribution and changes. Keep Xu/Lu as links and separate commentary in the public core.
- Run `python3 scripts/verify_sources.py` after reorganising sources or manifests. Check local Markdown links after moving documents. Source checksums alone do not validate figure interpretation.

No external lab, student or upstream project has been assigned work through this bundle. Issue drafts describe proposed work; assign ownership explicitly when adopting them.
